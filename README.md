# Mhazkha — Portfolio Website

Website portofolio interaktif untuk **Muhamad Afiq Zian Khairi (Mhazkha)**, siswa SMKN 1 Purbalingga (Web Developer, Machine Learning, Digital Designer & 3D Modeler).

Dibangun menggunakan **Vanilla HTML5, Vanilla CSS3, dan Vanilla JavaScript (ES6+)** dengan tema *Cyber-Modern Minimalist Dark Tech*.

---

## ✨ Fitur Utama

- **Top Green Pill Navigation**: Bar navigasi hijau interaktif di bagian atas tengah layar untuk membuka menu overlay secara instan.
- **Fullscreen Menu Overlay**: Navigasi cepat ke seluruh section (`About`, `Projects`, `Stack`, `Logs`, `Home`, dan tombol `Hire me`).
- **Home View**:
  - Hero profil ringkas & perkenalan diri.
  - Selected Works preview cards dengan tanggal `xx/xx`, kategori, tag teknologi, dan tombol interaktif `View`.
  - Section Contact dengan tautan email langsung (`ziankhairi14@gmail.com`) dan ikon sosial media aktif (GitHub, LinkedIn, Instagram).
- **About View**:
  - Avatar & informasi profil visual.
  - "Sedikit cerita Tentang saya" & "Detail profil".
  - **Journey & Milestones Section** di bagian bawah yang memuat timeline perjalanan belajar dan pencapaian.
- **Projects / Recent Works View**:
  - Showcase proyek asimetris modern.
  - Filter kategori cepat (*All*, *Web Development*, *Machine Learning*, *3D & Design*).
  - Modal detail proyek interaktif.
- **Stack View**:
  - Tech stack menggunakan **Logo/Icon SVG resmi** (HTML5, CSS3, JavaScript, PHP, Python, C++, React, MySQL, Linux, Git, GitHub, Figma, Blender).
  - Efek hover berpendar dan tooltip informasi keahlian.
- **Life Logs View**:
  - Catatan kegiatan di luar ngoding (kategori *Design*, *3D*, *Music*, *Games*).
  - Filter kategori dan kartu aktivitas visual.
- **Fully Responsive**: Tampilan optimal di perangkat mobile, tablet, dan desktop.

---

## 🛠️ Tech Stack

- **HTML5**: Semantik & Single Page Application (SPA) architecture
- **CSS3**: CSS Custom Properties (Variables), Flexbox & CSS Grid, Glassmorphism, Micro-animations
- **JavaScript**: Vanilla ES6+, SPA Hash Routing, Modal Manager, Dynamic Filtering

---

## 🚀 Menjalankan Secara Lokal

Cukup buka file `index.html` langsung di browser, atau jalankan local server:

```bash
# Menggunakan Python
python3 -m http.server 8000

# Atau menggunakan npx serve
npx serve .
```

Buka `http://localhost:8000` di browser.
